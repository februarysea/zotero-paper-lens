# Paper Lens 0.2.4 Beta

修复升级到 Zotero 10 后 Paper Lens 被禁用、入口消失的问题。此前安装包的兼容范围仅允许 Zotero 9；本版将清单上限扩展到 `10.0.*`，最低版本保留为 `9.0`。

本版使用相同插件 ID `paper-lens@februarysea.github.io`。在 Zotero「工具 → 插件 → 从文件安装插件」中安装 `paper-lens-0.2.4.xpi`，即可更新已有插件，保留原有账号授权和设置。

选区翻译、自动翻译、划词浮动框和阅读面板使用相同实现。本次不改动账号授权或模型后端。

## 验证范围

2026-10-14，已在 macOS / Zotero 10.0.6 中安装并验证 0.2.4：插件启用并加载，Paper Lens 设置页正常显示，已有 ChatGPT 授权和自动翻译开关保留，模型显示与实际 ID `gpt-6-luna` 一致。真实划词自动翻译完成后，划词浮动框与当前 PDF 阅读面板显示相同译文，复制按钮可用，浮动框位于可视区域内。

185 项 JavaScript 测试与 14 项发布和打包测试通过。此次验证未重新授权或保存笔记，未执行完整交互验收，也未测试 Windows 或 Linux 的 Zotero 运行环境。

## English

Fixes Paper Lens being disabled and disappearing after upgrading to Zotero 10. Earlier packages declared compatibility only with Zotero 9. This version extends the manifest maximum to `10.0.*` while retaining the minimum of `9.0`.

The addon keeps the permanent ID `paper-lens@februarysea.github.io`. Install `paper-lens-0.2.4.xpi` through **Tools → Plugins → Install Plugin From File** to update the existing addon and retain its account authorization and settings.

Selection translation, automatic translation, the selection popup and the reading pane keep their current implementation. Account authorization and the model backend are unchanged.

## Verification

On 2026-10-14, version 0.2.4 was installed and verified on macOS / Zotero 10.0.6. The addon is active and loads, the Paper Lens settings page works, existing ChatGPT authorization and the automatic translation setting are retained, and the model label matches the actual ID `gpt-6-luna`. A real selected passage completed automatic translation, with identical text in the selection popup and current PDF reading pane. Copying was enabled and the popup remained within the visible reader area.

All 185 JavaScript tests and 14 release and packaging tests passed. This verification did not repeat authorization or save a note, and did not cover every interaction or Zotero runtime use on Windows/Linux.
