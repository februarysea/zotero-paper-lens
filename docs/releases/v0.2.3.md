# Paper Lens 0.2.3 Beta

首个公开 Beta：在 Zotero 中用 Codex 模型翻译 PDF 选区。

## 功能

- 选中文字后翻译，译文流式显示在划词浮动框和原生阅读面板，两处共用一次请求。
- 滚动、复制、停止、重试，按需保存到论文笔记。
- 可选自动翻译，默认关闭；重新划选、关闭开关或切换标签页会取消相应任务。
- 独立 ChatGPT 授权，在 Zotero 内使用，无需启动 Codex。默认模型 `gpt-6-luna`，模型下拉位于 Zotero 设置。
- 中英文界面，翻译附带有限邻近正文和摘要，并显示实际上下文范围。

## 安装与迁移

下载 `paper-lens-0.2.3.xpi`，在 Zotero「工具 → 插件 → 从文件安装插件」中安装，再进入「Zotero 设置 → Paper Lens」授权。

固定 ID 为 `paper-lens@februarysea.github.io`。已有 `paper-lens@local` 开发版的用户，请先禁用或卸载旧插件再安装，避免两份同时运行。首次迁移需要手动安装，之后可从独立 Beta 渠道更新。既有 Paper Lens profile 授权记录和设置会保留；0.1.x 用户需要改用 Paper Lens 独立授权。

## 验证范围与限制

2026-10-12，维护者确认 0.2.3 本地功能版在 macOS / Zotero 9 环境完成了三项验证：ChatGPT 授权、真实选区翻译，以及重启 Zotero 后继续使用。已知开发环境为 Zotero 9.0.6。这是维护者报告的手动验证，不代表 CI 运行了真实账号流程。

首发安装包使用新的固定 ID；从旧 ID 迁移的安装流程仍需以新包实际验证。清单允许 Zotero 9，不包含 Zotero 10。Windows 和 Linux 尚未完成 Zotero 内实际验证；CI 跨平台检查仅验证代码测试与构建。自动翻译和浮动框的全部交互尚无完整人工验收记录。

仅支持选区翻译。扫描版需要已有可选文字，尚无 OCR、图片理解或公式排版。账号资格、可用模型和共享额度由 OpenAI 决定。论文选区与有限背景会发送给 OpenAI；详见 [隐私说明](https://github.com/februarysea/zotero-paper-lens/blob/main/PRIVACY.md)。Paper Lens 是独立项目，没有 Zotero 或 OpenAI 官方隶属关系。

安装包附有 `.sha256` 校验文件。首次公开版本通过 GitHub 的 Pre-release 分发。

## English

The first public Beta translates selected PDF text inside Zotero using Codex models. One request streams into the selection popup and native reading pane, with copy, stop, retry and paper-note saving. Optional automatic translation is off by default. Independent ChatGPT authorization runs inside Zotero without Codex; the default model is `gpt-6-luna`, with actual model IDs available in Zotero settings. Chinese and English UI are included.

Install `paper-lens-0.2.3.xpi` through Zotero's **Tools → Plugins → Install Plugin From File**, then authorize in **Zotero Settings → Paper Lens**. Disable or uninstall a development copy using `paper-lens@local` before installing the permanent `paper-lens@februarysea.github.io` identity. Existing Paper Lens profile registrations and preferences remain available; 0.1.x users need separate Paper Lens authorization. Subsequent updates use the separate Beta channel.

On 2026-10-12 the maintainer confirmed authorization, real translation and continued use after restarting a local 0.2.3 build on macOS / Zotero 9; the known development environment is Zotero 9.0.6. These are maintainer-reported manual checks, not real-account CI tests. Migration to the newly identified release package still needs installation verification. Windows/Linux runtime use, Zotero 10, and complete manual acceptance of automatic translation/popup interactions have not been established. Cross-platform CI only checks tests and packaging.

This Beta requires selectable text and does not provide OCR, image understanding or math rendering. OpenAI controls account eligibility, model access and shared usage. Selections and limited background are sent to OpenAI; see [Privacy](https://github.com/februarysea/zotero-paper-lens/blob/main/PRIVACY.md). This is an independent project without official Zotero or OpenAI affiliation. A SHA-256 file accompanies the package.
