# Paper Lens 0.2.5 Beta

新增默认开启的本地翻译缓存。完整译文自动保存，之后选中同一论文中的相同原文时，可直接在划词浮动框和阅读面板显示缓存译文，并标注「已缓存」，无需再次请求模型。失败、取消和未完成的译文不缓存，也不会自动创建笔记。

缓存匹配包括同一论文、规范化原文、实际提供的上下文、模型、目标语言及完整翻译规则。原文匹配允许 PDF 换行和连续空格的差异，不做语义相似或部分重叠匹配。上下文使用实际传入模型的裁剪后材料；页码、附件 key、提取字符位置和全文字符数不作为缓存指纹。模型、目标语言、规则或有效上下文改变后会生成新译文。

「重新翻译」绕过缓存，并在新译文完整生成后替换旧记录。「Zotero 设置 → Paper Lens → 清除翻译缓存」可删除本地记录。缓存位于当前 Zotero profile 的独立文件 `paper-lens/cache-v1.json`，仅保存原文、译文、匹配摘要（SHA-256 哈希）与创建和最近使用时间。论文、模型、语言、有效背景和规则仅参与哈希，不以明文字段保存；缓存不保存整篇正文或登录凭据，不随 Zotero 文库同步。容量为最多 1,000 条、约 10 MB，超限清理最久未使用的记录。

本版保留插件 ID `paper-lens@februarysea.github.io` 和 Zotero `9.0` 至 `10.0.*` 的兼容范围。安装 `paper-lens-0.2.5.xpi` 可更新已有插件，账号授权和设置继续保留。

## English

Adds a local translation cache enabled by default. Completed translations are saved automatically. Selecting the same original passage in the same paper can show the cached translation in both the selection popup and reading pane, marked **Cached**, without another model request. Failed, cancelled and incomplete translations are not cached, and caching does not create notes.

Matching includes the same paper, normalized original text, effective context, model, target language and full translation rules. Text normalization tolerates PDF line breaks and repeated spaces; it does not use semantic similarity or overlapping selections. The context fingerprint uses the actual clipped material sent to the model, excluding page labels, attachment keys, extraction offsets and full-text character counts. A change to the model, target language, rules or effective context generates a new translation.

**Retranslate** bypasses the cache and replaces the old entry only after a new translation completes. **Zotero Settings → Paper Lens → Clear translation cache** removes local records. The cache is a separate `paper-lens/cache-v1.json` file in the current Zotero profile. Only original text, translations, a matching digest (SHA-256 hash), and creation and last-use times are saved. Paper, model, language, effective background and rules enter the hash rather than being stored as readable fields. The cache contains no whole-paper body text or login credentials and is outside Zotero library sync. It holds up to 1,000 entries and about 10 MB, evicting least recently used entries when needed.

This version retains the addon ID `paper-lens@februarysea.github.io` and compatibility with Zotero `9.0` through `10.0.*`. Install `paper-lens-0.2.5.xpi` to update the existing addon while keeping authorization and settings.

## Verification

On 2026-10-14, version 0.2.5 was installed and verified on macOS / Zotero 10.0.6. The addon is active and its runtime module loads. Clicking **Translate selection** for the same actual passage showed **Cached** in the reading pane. The local `cache-v1.json` contained two entries with only `key`, `original`, `text`, `createdAt` and `lastUsed` fields, and file permissions were `0600`. A newly loaded cache module instance inside Zotero read an existing key from disk and returned a hit with identical translation text.

All 223 JavaScript tests, 14 release and packaging tests, structural checks and the build passed. These include 21 context tests covering consistency with effective clipped material, participation of the target language and full rules, and exclusion of page, attachment, offset and full-text-length changes. This verification did not include a full Zotero application restart or another addon reload, or Zotero runtime use on Windows/Linux.
